# 架构与云开发路线

当前所有页面通过 `services/index.js` 访问商品、需求、学校和模拟用户；`mock.js` 提供虚构种子。全局学校筛选存入本地存储，页面 onShow 重新读取，避免发布后列表过期。图片只用 WXSS 绘制占位，Tab 图标为本地 PNG。

## 接入顺序

1. 注册真实小程序 AppID，开通微信云开发环境，在环境设置安全配置。开发/测试/生产隔离；环境 ID 不是密钥，但不要把任何凭据写入仓库。
2. 引入受控的 `wx.cloud.init` 和云环境配置；将本地 services 替换成 Promise 接口，逐页用 async 调用、加载状态、错误提示和防重复提交。继续保留 Mock 模式供离线体验。
3. 创建 products、needs、schools 集合；云函数负责发布与分页查询，在服务端再次校验字段、价格、学校、文本长度。用服务端时间和文档 ID，设置学校/分类/时间查询索引。
4. 经用户同意后建立真实用户身份；由云函数上下文取得身份，禁止信任客户端 ownerId。设置最小数据库读写权限，仅允许本人管理自己的发布，防止直接篡改。
5. 图片使用微信选择媒体和云存储，限制数量、大小和类型；用户内容接入合规的内容审核、举报与下架机制。联系方式需明确用途和授权，避免全公开真实个人信息。
6. 加入云函数集成测试、分页/空数据/失败测试、真机验证。不要自动上传本机 Mock 发布记录到生产环境。

支付、私信、商业收费均不属于 V0.1；以后单独设计并评估平台要求。当前 cloudfunctions 只有预留说明，没有部署任何后端。
